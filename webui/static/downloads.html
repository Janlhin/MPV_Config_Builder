🚀 一键安装 mpv-lazy 整包

本工具是以 mpv-lazy 为底座的。这台机器还没装的话，这里可以直接装 —— 从 官方 release 取最新版，不内置也不转发任何文件。
流程：读取最新版本 → 下载到暂存目录 → 校验 → 解压 → 把 portable_config 放到目标目录。每一步都会显示进度，可以随时关掉页面（半个包会留着，下次接着下）。

📦 mpv 脚本与字幕字体

这里只装单文件的东西：脚本进 scripts\，字体进 fonts\。 全部从各项目的官方地址下载，本工具不内置、不转发任何第三方文件。
装过什么会记在本机清单里，列表上直接能看能卸。 只有点「下载」才会联网，其余操作全程离线。

❓ 说明

  • 装到哪儿：scripts\ 与 fonts\ 就在你选的配置目录里。 脚本放进去后 mpv 下次启动就会加载；字体还要在 mpv.conf 里写 sub-font=字体名 才会用上。
  • 「已装（未校验）」是什么意思：上游没公开提供 sha256，我们无法验证文件完整性。 但安装清单里记了你装到的那份文件的哈希 —— 所以至少能判断"装完之后有没有被改过"。
  • 为什么列表里没有 uosc：它现在只以 .zip 发布（仓库里没有单文件）， 属于下一阶段（L2「压缩包里挑文件」）的活。这一阶段故意不放必然 404 的条目。
  • VapourSynth 插件（滤镜）不在这里：那些 .dll 必须安装到 mpv 配置目录 之外，而且有版本与依赖要求，风险高一个量级，安排在 L3。
