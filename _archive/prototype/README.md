# 界面原型（HTML 静态稿）

**这不是程序**，只是用来确认观感的静态页面。直接双击 `index.html` 用浏览器打开即可，
不需要装任何东西。

## 怎么看

1. 打开 `index.html` → 四个模式卡片
2. 点进任意一个模式：
   - `basic.html` —— 基础模式（4 步向导，可点「下一步」走一遍）
   - `advanced.html` —— 进阶模式（侧边栏 + 参数行 + 说明抽屉，点参数右边的 `i` 看抽屉）
   - `expert.html` —— 完全体（829 项全量选项 + 类型徽章 + 默认值 + 冲突检测）
   - `hell.html` —— 😈 地狱模式（彩蛋：裸写配置，无保护）
3. 右上角 `🌓` 可以切深色/浅色

## 这一版想确认的设计点

| # | 设计点 | 在哪看 |
|---|---|---|
| 1 | 模式选择页（四个卡片） | `index.html` |
| 2 | 侧边栏替代横向标签页 | `advanced.html` / `expert.html` |
| 3 | 参数行 = 勾选 + 值 + **行内一行提示** | `advanced.html` 画质页 |
| 4 | 点标签就地展开完整说明 | `advanced.html` 第一行 |
| 5 | `i` 按钮 → 右侧说明抽屉（含"填入推荐值"） | 任意页点 `i` |
| 6 | 全量选项：类型徽章 + 范围 + 默认值 + 恢复默认 | `expert.html` |
| 7 | 搜索优先 + 分类 chips | `expert.html` |
| 8 | emoji 用在分区图标，状态用文字/符号 | 全站 |
| 9 | 深色 / 浅色两套 | 右上角 🌓 |
| 10 | 地狱模式要不要保留 | `hell.html` |

## 技术上意味着什么

原型就是 HTML/CSS。如果这版观感你认可，实现路线基本就定了：

- **pywebview + HTML/CSS**（推荐）：Python 当后端，`core/` 那 10 个模块直接复用，界面就是这套
- **Tauri**：同样用这套 HTML，但要装 Rust + Node 工具链，体积更小（3–10MB）
- 如果最后不想要 WebView，就得用 PySide6 重新实现同样的观感（工时更长，且"好看"要手调）

## 请注意

- 页面里的数据和选项都是**示意内容**，不代表最终功能范围
- 所有交互都是假的（点"生成配置"不会真的写文件）
- 想要什么改动直接说：配色、字号、间距、卡片风格、侧边栏分组、emoji 用哪些……

## 改起来很快

改 `style.css` 一个文件就能换掉全站观感（颜色变量都在 `:root` 里）。
你可以直接说"主色换成绿色""卡片不要圆角""侧边栏再窄一点"，我改完你刷新就能看到。
