# 既有约定（别推翻）

> 本文原为 `AGENTS.md` §5。2026-11-07 按规范 v1.20.0 §`agents-md` 迁出：
> 这些是**改动前才需要核对**的结构性约束，不是每次会话都要读的规则。
> 与 `AGENTS.md` §2 的硬约束同级 —— 「迁出」只是位置变化，效力不变。

- `tools/` **只有 4 个文件**：`build.py`（生成）/ `verify.py`（验证）/
  `uidriver.py`（浏览器驱动，被实机脚本共用）/ `_dump_bindings.lua`。
  **新增验证脚本请加进 `verify.py` 的 `cmd_*` 子命令，不要新建文件。**
- `.githooks/pre-commit` 是**提交门禁的入口，不是规则的存放处**：它只负责把
  `verify.py precommit` 跑起来，判断规则全在 `verify.py` 里。改规则改那里，
  别在钩子文件里堆逻辑——否则「门禁判什么」会有两份答案。
- 前端只有 `webui/static/` **一份**：`tauri/src-tauri/tauri.conf.json` 的 `frontendDist`
  直接指过去（`../../webui/static`），**不许在 `tauri/` 下复制副本**——复制就会漂移，
  然后「测试全绿、窗口里跑的是另一套页面」。已移除的 `electron/renderer/` 正是这么坏掉的。
- 旧 Tkinter 界面已**移出仓库**，归档在 `..\MPV_Config_Builder_legacy\`
  （保留、能在本机跑、有自检，但**不维护**）。不要试图「修」它。
- 界面上能读的 4 份文档由 `webui/server.py` 的 `DOCS` 白名单驱动；
  增删那份清单要改那里，同时改 `tools/verify.py` 的必带文件清单。
- 传输层可替换（HTTP / stdio）：页面里**任何**直接 `fetch('/api/...')` 都会在外壳
  （stdio 通道）下**静默失效**，全部走 `API.xxx()`（`tests/test_frontend_transport.py` 静态守着）。

## 结构性约束（2026-10-20 架构复核的结论）

- **分层方向**：`core/` 不许 import `webui/` / `tauri/` / `tools/` / `tests/`（`verify.py deps` 判）。
  但 `webui/server.py` 至今把应用层与 HTTP 适配同居、`api.py` 还反向 `getattr(server, …)`
  —— 这是**已登记偏差**（T28），不是可以照着抄的范式；新接口别再往这层堆。
- **传输门面**：页面只经 `API.xxx()`；`API.get('/api/…')` 这类字面量是历史写法，新代码用具名方法。
- **前端状态**：`webui/static/state.js` 只有一份全局 `APP`；新增写入走 `patch(partial)`，
  别再散落 `APP.x = …`（约 30 处历史直接赋值属已登记偏差）。
- **800 行预算**：现有 5 个文件超限（`tools/verify.py`、`webui/static/state.js`、`webui/server.py`、
  `webui/static/i18n.js`、`core/schema.py`）—— **历史偏差不回溯拆分**，但**新文件不许超 800 行、
  现有文件不许继续增长**（门禁见 T27）。
- **单点定义**：`tools/` 只有 4 个文件；钩子只做分发；前端只有一份；传输只有 HTTP / stdio 两根线。

## 实测判据（原 `docs/踩过的坑.md`，2026-11-17 并入）

> 这些是**实测出来的**，不是看代码猜的；完整过程在 git 历史（2026-11-17 之前的 `踩过的坑.md`）。
> 判据比结论更值钱：下次遇到同类问题，先照着验一遍。

**mpv 本身**

- 8 位颜色是 `#AARRGGBB`（透明度在前）；`#` 之后一律算注释 → 颜色值必须写成 `"#RRGGBB"`。
- 光写选项名 = `=yes`；`vf=` 路径含空格必须整体加引号（否则 mpv 报解析失败）。
- 未改动的行可以逐字节原样写回；include 链里引的都是 profile（跟随 include 不会污染全局值）。

**下载 / mpv-lazy**

- 完整包是分卷，`-noVS` 包不能要；"选体积最大的"会挑错。分卷是否齐全读 **7z 文件头**
  （三个字段全 `0xFF…FF` 表示后面还有卷）。
- `uosc.zip` 里 11.3 MB 是别的平台二进制（`ziggy-darwin` + `ziggy-linux`）；Windows 只留 `ziggy-windows.exe`。

**界面 / i18n**

- 原生 `<datalist>` 气泡不在 DOM、不吃 CSS、截图抓不到 → 只能自绘（`tests/test_combo.py` 钉死）。
- 只测一种传输等于没测"传输可替换"：4 处直连 `fetch` 在浏览器里全正常，stdio 下静默失效。
- 页面报"剩余汉字"可能是后端返回的数据串 → 先 CDP dump 归因，**别拿前端词典去盖后端字符串**。
- `data-i18n-ph` 会被词典兜底覆写回原文；未标记的静态文案一律走词典。
- 运行时拼的字符串要过两道关：英文态渲染 + 切语言时的词典重扫（长词条优先）。
- "切后剩 0 汉字"只测了切换那一刻；confirm / toast 这类操作后才出现的串要单独 grep。
- 构建时取一次文本会把语言冻在加载那一刻 → **存键不存文本**，渲染时现取。
- 切语言重绘必须走缓存响应，不能重新请求（否则丢用户未保存的编辑）。
- `grid-template-rows` 展开动画要三层结构（容器 padding / 裸裁剪层 / 视觉层）；
  收起后剩一条缝 = 漏算了 margin 或 padding。

**测试 / 验证方法**

- 高风险重构用**系统枚举**，不靠手挑用例（55 个手选用例全绿，4699 组枚举立刻抓出真 bug）。
- 报错和成功同时出现时先怀疑检查本身 —— 一个永远不会成功的断言比没有断言更糟。
- 字符串匹配会撞文档串（注释里写着"不许 import http.server"被判违规）→ 改用 AST 判据。
- "文件都在"不等于"能用"：打包产物齐全但崩在 import，只有真起进程才看得见。
- `where py` 成功 ≠ `py -3` 能跑；判断"在不在"不够，必须真跑一下解释器。
- 固定 sleep 是 CI 间歇红的来源：等条件，别等时长；红过一次要翻全部运行历史判断是竞态还是真缺陷。
- 实机检查只要触发"写"，先把最外层 I/O 换成桩 —— 页面会自己探测环境并自动填 target。
- 钩子不能写成 `.ps1`：Git for Windows 用 `-File` 执行无扩展名文件，被扩展名校验卡死（Q-002）。
- 断点续传必须验对方真的回了 `206` + 起始字节匹配，否则截断重下。
- `Path("")` 在 Windows 上等于当前目录；`Path.write_text()` 默认按平台写 CRLF 且非原子。
- 随技术栈移除的历史教训（原文见 git）：`.bat` BOM / cmd 预读头部、`ELECTRON_RUN_AS_NODE` 污染、
  GPU 进程崩溃、Electron 打包。
