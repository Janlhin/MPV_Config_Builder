# Third-party ledger

**Scope:** data, text and runtime-fetched resources used by this project. This
page is for auditors; the distributor-facing attribution text is
[`NOTICE.txt`](NOTICE.txt). Machine-checkable hashes are in
[`SHA256SUMS`](SHA256SUMS), generated by `python tools/gen_compliance.py`.

## Principle

This repository **does not bundle or forward third-party binaries**. Download
centre entries are fetched from each project’s official address only when the
user clicks; no copy is kept in the repository. Those entries therefore have no
local hash — that is a design choice, not an omission.

## Why GPL-3.0

`data/mpv_options_zh.json` embeds Chinese option descriptions from mpv_doc-CN
(GPL-3.0). GPL-3.0 is viral; distributing this derivative data requires the
whole distribution to comply with GPL-3.0. The full license text is `LICENSE`;
the attribution is `NOTICE.txt`.

## Known gaps

1. **No hash pinning for runtime downloads.** The user receives whatever the
   upstream URL returns; rolling `latest` URLs can change.
2. **No one-click reproduction script for all bundled data.** `SHA256SUMS` can
   be regenerated, but it is not yet wired into CI as a stale check.
3. **Upstream licenses are not copied into this file.** They live in
   `core/dlcenter.py` and are shown in the UI; copying them here would create a
   second, drifting copy.

Gaps 1–2 are tracked as follow-up work, not hidden.
