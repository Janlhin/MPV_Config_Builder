## 一、待做（已确定要做，只是没做）

### 1. Electron 界面「像个正经软件」那批

现状：**能用，但有明显的"套壳感"**。缺的都是桌面软件的常规配置。

| 缺什么 | 现状 | 影响 |
|---|---|---|
| **键盘快捷键系统** | 基本全靠鼠标 | 改一个选项要点半天 |
| **右键菜单** | 没有 | 想「恢复默认 / 复制选项名 / 看手册原文」无从下手 |
| **底部状态栏** | 没有 | 看不到当前配置文件路径、改动几处、后端是否活着 |
| **后端挂了有提示** | **白屏，什么都不说** | 用户以为软件坏了 |
| **加载中的进度** | 有些地方直接空白 | 读配置、扫描 shader 目录时像卡死 |
| **自绘标题栏** | 系统默认灰条 | 一个改动就能让"套壳感"少一半 |

> 用户原话：「快捷键 配置体检这种体验不是很好」—— 指的就是这批。
> 不是这两个功能做得差，是它们**不像"软件的一部分"**。

但网页版早就有下载中心和一键安装了（R-8w 做的）。

**全代码里到底还有多少条过期的，没有排查过。**
文案是写死在 HTML 里的，改功能时容易忘了改它。

### 3. 功能上的缺口

| 项 | 说明 |
|---|---|
| **本地 HTTP 的 Origin 校验** | 现在浏览器里别的网页能打你本机的服务端口。stdio 模式没这问题，网页版有 |
| **英文版** | 现在全中文。要做 i18n 层 + 英文选项说明（得从 mpv 的 `DOCS/man/options.rst` 取，`--list-options` 里没有描述） |
| **VS 插件一键安装** | 往 VapourSynth 目录装插件。风险较高（写到 mpv 配置目录外面） |
| **`prefers-reduced-motion` 适配** | 无障碍缺口。小活，**不管加不加动效都该补** |
| **界面动效** | 要不要加、加哪些 —— 一直没拍板 |

安装器未签名 → Windows SmartScreen 会拦一次（「更多信息 → 仍要运行」）。
要消除得买证书，**不是技术问题**。

## 三之二、已定的规则（不是待做，是约定）

### 版本号怎么涨

**唯一来源是 `core/schema.py` 的 `VERSION`。** 改完跑 `py tools/sync_version.py`
把版本刷进 `electron/package.json`（那边打包时要用）。忘了跑也没事 ——
`tests/test_version.py` 有一条测试钉住两边相等，会红。

| 什么时候 | 怎么涨 | 例 |
|---|---|---|
| 小更新（改文案、修 bug） | 最后一位 | 0.1.0 → 0.1.1 → 0.1.2 |
| 大更新（加功能） | 中间那位 | 0.1.x → 0.2.0 |
| 觉得能正式推荐给别人了 | 第一位 | 0.x → 1.0.0 |

所以 **0.x 阶段就是「还在做」的意思**。

> 2026-09-14 顺带定：**界面只显示软件版本**，不再显示「2.0」。
> `APP_VERSION = "2.0"` 那个常数留着，但只为 `legacy/` 那个旧界面服务
> （主界面测试会拦着不让用它）。生成的配置抬头也从
> `# MPV Config Builder 2.0` 变成了 `# MPV Config Builder`。
> 合并写入不受影响 —— 它认的是另一条标记「由 MPV Config Builder 写入」。
