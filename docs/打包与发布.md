## 跑测试 / 发布前自检

```
python -m unittest discover -s tests -t .
python tools\verify.py docs     # 文档数字对不对
python tools\verify.py          # 发布前一次跑完（加 --offline 跳过联网检查）
```

⚠ `tests\__init__.py` 是 0 字节但**必须留着**，删了测试跑不起来。

`verify.py` 的全部子命令：`all`（发布前自检）/ `precommit`（提交门禁）/
`docs` / `i18n` / `status` / `ctxmenu` / `hotkeys` / `motion` / `topnav` /
`stdio` / `presets` / `ui` / `electron` / `packaged` / `pack` / `conflicts`。

## 打包发布（顺序不能颠倒）

### ① 打后端（Electron 要把它塞进 resources\backend\）

```
python -m PyInstaller packaging\backend.spec
python tools\verify.py pack          # 验产物真的能用（21 项）
```

### ② 打 Electron 应用 + 安装器

```
cd electron
npm install                          # 第一次要下 Electron 二进制（几百 MB）
npm run dist                         # 产出 release\MPV Config Builder-<版本>-Setup.exe
cd ..
python tools\verify.py electron       # 开发形态（23 项）
python tools\verify.py packaged       # 打包形态（13 项）
```

普通用户拿到安装包双击就行 —— **不需要装 Python**（后端 exe 自带解释器）。

### 打包命令要带全（否则文档页与选项库会空）

```
--add-data "data;data"  --add-data "webui\static;webui\static"
--add-data "LICENSE;."  --add-data "NOTICE.txt;."   ← 合规要求
--add-data "*.md;."（界面里的文档是实时渲染它们的）
```

打包产物附上 GPL-3.0 全文（就是仓库里的 `LICENSE`）。

## 已知限制

- 安装包约 97 MB（Electron 本身占大头）
- **没有代码签名** → Windows SmartScreen 会拦一次（「更多信息 → 仍要运行」）
- 只支持 Windows
- 安装器很重，所以仓库里不含 node_modules / release（都是产物，随时重生成）

## 目录结构明细

```
core\                     核心逻辑，与界面无关（26 个模块）
    schema.py             参数表 / shader·vpy 清单 / 原生选项 / 路径辅助
    writer.py             写回（include / merge，原编码、原子写）
    loader.py             读取解析（[profile] 小节单独列出，不混进全局值）
    analyze.py / report.py / score.py / diff.py   体检与报告
    conflicts.py          17 条冲突规则（每条注明依据来源）
    keys.py               按键绑定读写
    vpy.py                多脚本融合
    installer.py / dlcenter.py   mpv-lazy 一键装 / 下载中心
    hardware.py           分辨率 / 刷新率 / GPU 探测
    i18n.py               后端文案双语上下文（T14）
    update.py             版本检测
data\
    mpv_options_zh.json   829 条原始选项 + 726 条中文说明（来自 mpv_doc-CN，GPL-3.0）
                          其中 16 条是命令行专用（mpv 标注 not in config files），
                          读取时会滤掉，所以界面里是 813 项
    mpv_keybindings.json  209 条内置默认按键（从你自己的 mpv 里导出）
    mpv_commands.json     86 条 mpv 命令（--input-cmdlist）
tools\
    build.py              构建/生成总入口（options-db / keybindings / icon / ps1 / version / golden）
    verify.py             验证总入口（子命令见上）
    uidriver.py           浏览器 / CDP 公共驱动（实机验证脚本共用）
    _dump_bindings.lua    mpv 导出按键的临时脚本（build.py keybindings 用）
packaging\
    backend.spec          PyInstaller 配方：把后端打成独立 exe
electron\
    main.js               主进程：spawn 后端走 stdio、单实例、CSP、自绘标题栏
    preload.js            安全边界：三个窄导出（INVOKE / INFO / WINDOW）
    scripts\sync-renderer.js  把 webui\static 复制到 electron\renderer（单一来源）
    renderer\             构建期复制产物，**不要手改、不入库**
tests\                    单元测试（765 项，含接口端到端与真实脚本测试）
```
