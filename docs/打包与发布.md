## 打包发布（顺序不能颠倒）

### ① 打后端（外壳要把它 spawn 起来，不走解释器）

```
python -m PyInstaller packaging\backend.spec
python tools\verify.py pack          # 验产物真的能用（21 项）
```

### ② 打 Tauri 外壳

```
cd tauri\src-tauri
cargo build --release               # 产出 target\release\mpv-config-builder.exe
cd ..\..
python tools\verify.py tauri        # 25 项（静态 + 实机；实机要 debug exe 在）
```

**安装器暂时没有。** `tauri.conf.json` 里 `bundle.active` 还是 `false` ——
2026-11-16 换外壳时 Electron 连同它的安装包产线一起被移除，Tauri 的打包
（`cargo tauri build`，需要下载 WiX/NSIS）**尚未开启、也未验证过一次**。
要恢复「双击安装」的交付形态，必须先完成这件事并把下面几项定下来：

1. `bundle.active = true` + `bundle.targets`（Windows 选 `nsis` 或 `msi`）；
2. 把 ① 的后端产物放进 `bundle.resources`，`main.rs` 里改成找打包后的路径；
3. 卸载旧版 Electron 的残留（旧安装器写进 `%LOCALAPPDATA%` 的东西没人再清）；
4. 真正跑一次 `cargo tauri build` 并实机装一遍（目前**没有任何自动验证**覆盖安装器）。

在 ②③④ 完成之前，交付形态只有「从源码跑」和「自己 `cargo build` 出 exe」两种。

### 打包命令要带全（否则文档页与选项库会空）

```
--add-data "data;data"  --add-data "webui\static;webui\static"
--add-data "LICENSE;."  --add-data "docs;docs"   ← 合规要求（NOTICE.txt 与界面文档都在 docs\）
```

打包产物附上 GPL-3.0 全文（就是仓库里的 `LICENSE`）。

## 已知限制

- **没有安装包**：Tauri 打包尚未开启（`bundle.active=false`），Releases 里暂时没有 `Setup.exe`。
  现有的两个产物是「PyInstaller 打的后端 exe」和「cargo build 出的外壳 exe」。
- **没有代码签名**：一旦安装包恢复，Windows 仍会拦一次 SmartScreen（「更多信息 → 仍要运行」）。
- 只支持 Windows（Tauri 用系统 WebView2；macOS/Linux 分支从未编译过）。
- 仓库里不含 `node_modules` / `target/` / 任何 release 产物（都是产物，随时重生成）。

## Tauri 桌面外壳（2026-11-16 起是**唯一**外壳）

Electron 已在 2026-11-16 整体移除（`electron/` 目录、`electron-builder` 打包链路、
`verify.py electron|packaged`、`test_electron_exit.py` 全部删除）。现在窗口形态只剩
Tauri 这一套，用的是 **`3.0.0-alpha.6`**（不是 2.x 稳定线）。

判据仍是四条：窗口起、9 个页面能跑、通信通、退出不留孤儿。

```
cd tauri\src-tauri
cargo build                      # 首次约 1m20s，之后增量 30–40s
.\target\debug\mpv-config-builder.exe
```

- **前端只有一份**：`tauri.conf.json` 的 `frontendDist` 直指 `../../webui/static`，
  不在 `tauri/` 下复制副本（副本会漂移，已移除的 `electron/renderer/` 已踩过）。
- **后端走 stdio，不开端口**：`python webui\server.py --stdio`，可用 `MPVCB_PYTHON` /
  `MPVCB_ROOT` 覆盖。页面侧 `api.js` 只看 `__MPVCB_INVOKE__` 在不在，所以 9 个页面一行没改。
- **退出先礼后兵**：关 stdin → 等 1.5s → 不退才 kill（立刻 kill 会打断正在写的 `mpv.conf`）。
- **Tauri 3 的两个坑**（已写进 `Cargo.toml` / `main.rs` 注释）：
  ① 运行时拆包了，`Builder::default()` 不再自带 —— 必须加 `tauri-runtime-wry` 依赖并
  `.runtime(tauri_runtime_wry::Wry::default())`，否则启动即 panic（`RuntimeNotConfigured`）；
  ② `tauri-build` 没有 alpha.6，钉在 `3.0.0-alpha.4`（最新）。
  另外国内 `static.crates.io` 现在 SSL 握手失败，紧急时可放 `src-tauri/.cargo/config.toml`
  指 rsproxy（该目录已 gitignore）。
- **没做（已登记降级）**：`tauri build` 安装包（`bundle.active=false`）、自绘标题栏（R-29）、
  原生菜单、单实例锁。页面顶栏在 Tauri 下没有拖拽区（系统标题栏接管）。
- **验证**：`py tools\verify.py tauri`（25 项：静态 + 实机）。需要 exe 才跑实机；
  进 `verify.py --offline` 全量时没有 exe 就跳过，不算失败。**不进 `precommit`**（首次编译太重）。
